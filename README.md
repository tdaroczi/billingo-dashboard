# Billingo MI irányítópult bemutató

Fiktív adatokkal működő, magyar nyelvű Billingo-inspirált MI irányítópult bemutató kisvállalkozói panelbeszélgetéshez.

Publikus demó:

https://billingo-mi-demo-daroczi.netlify.app

Fontos: ez a verzió nem használ élő Billingo adatokat. Minden ügyfél, számla és összeg fiktív.
